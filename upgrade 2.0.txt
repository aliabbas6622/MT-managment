==================================================
OFFLINE FIRST
==================================================

The application must continue working even without internet.

Requirements:

- Local SQLite database
- Neon PostgreSQL as cloud database
- Background synchronization

Workflow:

User edits data

↓

Save immediately to SQLite

↓

Insert into sync_queue

↓

Background worker syncs to Neon

↓

Mark sync completed

The UI must never freeze while syncing.

==================================================
SYNC ENGINE
==================================================

Create a professional synchronization engine.

Requirements:

- Detect internet connectivity
- Automatic retry
- Exponential backoff
- Batch uploads
- Batch downloads
- Conflict resolution
- Queue processing
- Background worker
- Sync indicator in UI

Avoid excessive requests.

Use a configurable sync interval.

Example:

30–60 seconds

or immediate sync after important changes.

Never spam the database.

LICENSE VALIDATION
==================================================

Activation works using a secure activation token.

Flow:

User enters token

↓

Send securely to backend

↓

Backend validates token

↓

If valid:

Store encrypted license locally

Enable Premium features

Update UI immediately

If invalid:

Show friendly error

Never hardcode tokens.

Never validate only on the client.

Design the licensing system so it can support:

- expiration
- perpetual licenses
- disabled licenses
- future subscription model
